## 🌟 核心功能特性

### 1. 24 小时连续时间图谱 (24h Spectrum Bar)
- **光阴瀑布**：00:00~24:00 连续时间流，已记录时段以对应分类高亮显示，空白时段自动感应并提供“一键补录”。
- **全景洞察**：顶部色条实时计算全天时间利用率。

### 2. 极致顺滑的移动端交互 (Mobile-First Touch)
- **整块点击编辑**：轻按时间流中的任意卡片，即刻拉起编辑抽屉，无需再用手指精细瞄准小按钮。
- **快捷时长增量**：内置 `+15m`、`+30m`、`+45m`、`+1h`、`+1.5h` 快捷按钮，两秒完成一段记录。
- **大号删除防误触**：抽屉内配备醒目红色大号删除键。

### 3. 全能活动分类自定义 (Category Management)
- 支持自由重命名默认分类名称（如黄帝内经研读、易筋经/八段锦、代码动画、日常起居等）。
- 支持自由新增分类：自选 Emoji 图标、自选颜色、自由标记“高价值专注”或“摸鱼消耗”。
- 支持不常用分类一键删除与初始预设一键恢复。

### 4. 🌿 与 Obsidian 知行日志双保险联动
- **标准对账格式**：输出 `- **HH:mm - HH:mm**：【分类】事项与觉受`，与用户的知行日记规范 100% 契合。
- **保险 1：【📋 一键复制对账】**：点一下直接存入剪贴板，手机或电脑直接粘贴，彻底告别 AI 二次转录，100% 免疫任何 VPN/TUN 干扰。
- **保险 2：【🚀 局域网直通写入】**：电脑后台托盘服务接收手机打卡数据，0.01 秒自动精准刷新当天日记的 `### ⚡ 暮夜对账` 段落，多次提交不重复。

### 5. 睡前自我对账与黑洞警示
- **时间黑洞警报**：单独统计醒后赖床刷手机、无意义摸鱼等耗损时间，给出警示觉察。
- **睡前三问**：5星掌控感评分 + 肯定专注投入 + 觉察时间小偷 + 明日微调策略。

## 🔒 隐私与安全承诺

- **Local-First 本地优先**：所有打卡数据、身体觉受与反思日记**全部 100% 保存在用户设备本地的 LocalStorage 中**。
- **绝不上传公网**：GitHub Pages 仅托管纯前端静态代码，绝不上传任何用户的个人数据。
- **离线即用**：支持在无网环境下完全正常记录与统计，支持全量 JSON 数据备份与恢复。
