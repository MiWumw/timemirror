💡 时间觉知法则

1. 不加评判地记录： 早上刷了30分钟手机没关系，关键是诚实地记录下来。记录本身就是觉知的开始。

2. 降低启动阻力： 醒来把手机放在手够不着的地方，用实体闹钟或把水杯放在床头。

3. 柳比歇夫统计法： 经过2~3周的连续记录，你的潜意识会自动提醒你“当下做的事情是否值得”。

🌐 多端生态与云端同步预留

📱 跨平台准备： 代码底层采用 Web 标准模块化规范，已预留针对 Android APK、iOS、iPadOS、Windows 的打包容器层（Capacitor / Tauri），可随时打包原生应用。

☁️ 云端同步接口： 内部已抽象 StorageAdapter 数据适配层。现阶段为纯离线保护隐私，未来只需开启云适配器，即可平滑支持多设备端到端加密同步，无需重构现有记录。

🧩 应用矩阵融合： 项目独立位于 d:\fs\timemirror，为日后新增打卡、笔记、知识库等多款 APP 并形成“个人数字聚合中心”保留了标准扩展空间。

🛠️ 体验与数据管理

本应用采用 本地优先（Local-First） 架构，全部数据保存在当前设备的本地存储中，离线可用，绝不上传任何云端服务器，全面守护你的个人作息隐私。

📱 如何在手机上安装使用
  1. 确保手机与电脑在同一 Wi-Fi 或局域网。
  2. 在手机自带浏览器（如 Chrome、Edge、华为浏览器、小米浏览器）中打开本站网址。
  3. 点击浏览器菜单（右上角三个点或底部分享按钮）。
  4. 选择 “添加到主屏幕” 或 “安装应用”。
  5. 手机桌面上就会出现《时镜》App 图标，打开后全屏无地址栏，完全等同原生 App！
